Understand the algorithm

What does Beam Search do?

Beam Search is a heuristic search strategy that explores multiple candidates while limiting how many states survive at each level.

🌱

Start with candidates

The algorithm begins with an initial state and expands it into possible next states.

📊

Score possibilities

Every generated candidate receives a heuristic score that estimates how promising the state is.

✂️

Prune the rest

Only the best candidates up to the selected beam width are kept for the next search level.

🎯

Reach a goal

The surviving candidates continue expanding until the target depth is reached or a goal is discovered.

Implementation

See the core idea.

This simplified implementation captures the central idea: expand candidates, score them, sort them, and retain only the strongest beam-width candidates.

beam-search.js 
function beamSearch(start, beamWidth) {
let beam = [start];

while (beam.length > 0) {

    const candidates = [];

    for (const state of beam) {
        const nextStates =
            expand(state);

        candidates.push(...nextStates);
    }

    candidates.sort(
        (a, b) => b.score - a.score
    );

    beam =
        candidates.slice(0, beamWidth);

    if (goalReached(beam)) {
        return beam;
    }
}

return null;


}
