Understand the algorithm

So, what is Dijkstra?

Dijkstra's algorithm finds shortest paths from a starting node to other nodes in a weighted graph when edge weights are non-negative.

🎯

Start with zero

The starting node receives distance 0. Every other node begins with an unknown distance, represented here as infinity.

🔎

Pick the closest

The algorithm repeatedly selects the unvisited node with the smallest currently known distance.

🔗

Relax the edges

For each neighbor, Dijkstra checks whether travelling through the current node produces a shorter route.

🏁

Build the route

The predecessor of each improved node is stored. Those predecessors can later reconstruct the shortest path to the destination.

Implementation

See the core idea.

This simplified implementation captures the central distance-selection and relaxation process.

dijkstra.js 
function dijkstra(graph, start) {
const distances = {};
const visited = new Set();

for (const node of graph) {
    distances[node] = Infinity;
}

distances[start] = 0;

while (visited.size < graph.length) {

    const current =
        findClosestUnvisited(
            distances,
            visited
        );

    if (current === null) {
        break;
    }

    visited.add(current);

    for (const edge of graph[current]) {

        const newDistance =
            distances[current] + edge.weight;

        if (
            newDistance < distances[edge.node]
        ) {
            distances[edge.node] = newDistance;
        }
    }
}

return distances;


}
Time Complexity O((V + E) log V
Space Complexity O(V)
