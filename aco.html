Understand the algorithm

How does ACO work?

Ant Colony Optimization is a population-based optimization method inspired by how real ants use pheromone trails to collectively discover efficient paths.

🐜

Construct solutions

Each artificial ant builds a solution step by step. In this travelling-salesperson problem, an ant chooses the next unvisited city probabilistically.

🧪

Pheromone trails

Edges receive pheromone reinforcement according to the quality of the tours that used them. Better routes therefore receive stronger collective feedback.

💨

Evaporation

Existing pheromone is multiplied by an evaporation factor. This reduces the influence of outdated paths and helps maintain exploration.

⚖️

Explore + exploit

The transition probability combines pheromone intensity with a distance-based heuristic, balancing learned experience with the attractiveness of nearby cities.

Implementation

The core ACO rule.

The simulation uses the standard probabilistic transition rule followed by pheromone evaporation and solution-dependent deposition.

aco.js 
// Probability of choosing city j from city i
function transitionProbability(i, j, visited) {

    if (visited[j]) {
        return 0;
    }

    const pheromone =
        Math.pow(tau[i][j], alpha);

    const heuristic =
        Math.pow(1 / distance[i][j], beta);

    return pheromone * heuristic;
}

// Evaporation
for (edge of edges) {
    tau[edge] *= (1 - evaporation);
}

// Deposit pheromone
for (tour of ants) {

    const contribution =
        Q / tour.length;

    for (edge of tour) {
        tau[edge.from][edge.to] += contribution;
        tau[edge.to][edge.from] += contribution;
    }
}
