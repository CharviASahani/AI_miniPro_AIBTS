How it thinks

One question:
“Who looks closest?”

Unlike Dijkstra's algorithm, Greedy Best-First Search does not prioritize the total distance already travelled. It focuses on the heuristic estimate h(n) of the remaining distance to the goal.

1

Start

Put the starting node into the frontier.

2

Compare

Look at the heuristic h(n) of available nodes.

3

Choose

Select the node with the smallest heuristic value.

4

Repeat

Continue until the goal is reached or the frontier becomes empty.

Understand the algorithm

Greedy means “look ahead.”

The algorithm uses a heuristic to estimate which frontier node appears closest to the goal. This can make it fast, but the heuristic-only strategy does not guarantee the shortest path in a general weighted graph.

🎯

Heuristic h(n)

A heuristic estimates how close a node is to the goal. Smaller values are preferred by Greedy Best-First Search.

⚡

Fast decisions

Because the algorithm concentrates on the estimated remaining distance, it can avoid exploring many nodes.

🗺️

Frontier

The frontier contains discovered nodes that have not yet been expanded. The smallest heuristic gets priority.

⚖️

Not always optimal

Greedy Best-First Search ignores the cost already travelled. Therefore, its first discovered route to the goal may not be the shortest route.

Implementation

The core idea in code.

The important operation is selecting the frontier node with the smallest heuristic value.

greedy-bfs.js 
function greedyBestFirstSearch(graph, start, goal) {
const frontier = [start];
const visited = new Set();
const parent = new Map();

while (frontier.length > 0) {

    frontier.sort(
        (a, b) => heuristic[a] - heuristic[b]
    );

    const current = frontier.shift();

    if (current === goal) {
        return reconstructPath(
            parent,
            start,
            goal
        );
    }

    if (visited.has(current)) {
        continue;
    }

    visited.add(current);

    for (const neighbor of graph[current]) {
        if (!visited.has(neighbor)) {
            parent.set(neighbor, current);
            frontier.push(neighbor);
        }
    }
}

return null;


}
