Understand the algorithm

What is IDDFS?

Iterative Deepening Depth-First Search combines the memory efficiency of DFS with the shallow-solution behaviour of breadth-first search.

🔁

Repeat with a limit

IDDFS runs a depth-limited DFS repeatedly. The first search may only explore depth 0, then depth 1, then depth 2, and so on.

🌊

Shallow first

Because smaller depth limits are searched first, IDDFS can find a shallow goal without storing an entire breadth-first frontier.

🧠

Memory efficient

Like DFS, the algorithm mainly needs to keep track of the current search path, making its memory requirement much smaller than storing every frontier node.

🎯

Stop at the goal

Once the target is reached within the current depth limit, IDDFS stops and returns the discovered path.

Implementation

The recursive idea.

The core of IDDFS is a depth-limited DFS called repeatedly with a larger limit.

iddfs.js 
function depthLimitedSearch(node, goal, limit, path) {

if (node === goal) {
    return path;
}

if (limit === 0) {
    return null;
}

for (const child of graph[node]) {

    const result =
        depthLimitedSearch(
            child,
            goal,
            limit - 1,
            [...path, child]
        );

    if (result !== null) {
        return result;
    }
}

return null;


}

function iddfs(start, goal) {


for (
    let depth = 0;
    ;
    depth++
) {

    const result =
        depthLimitedSearch(
            start,
            goal,
            depth,
            [start]
        );

    if (result !== null) {
        return result;
    }
}


}
