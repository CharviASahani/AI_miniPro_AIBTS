Behind the state

The hidden world has structure.

A Hidden Markov Model separates what we can observe from the underlying state that generated those observations.

H

Hidden states

The actual condition of the system is not directly visible. Here the hidden states are Sunny, Cloudy, and Rainy.

O

Observations

We observe signals produced by the hidden state, such as carrying an umbrella, drinking coffee, walking, or visiting a library.

→

Transitions

The transition matrix describes how likely one hidden state is to follow another hidden state.

P

Emissions

Emission probabilities describe how likely each observation is when the system is in a particular hidden state.

Viterbi pipeline

From observation to explanation.

Viterbi does not simply guess each state independently. It considers the entire sequence while preserving the best predecessor for every state.

01
Initialize Combine initial-state and emission probabilities.
02
Recurrence Select the strongest predecessor for each state.
03
Backtrack Follow stored predecessor pointers backwards.
04
Decode Reverse the path to reveal the hidden sequence.
Implementation

The algorithm behind the screen.

This is the core dynamic-programming recurrence used by the interactive decoder above.

viterbi.js 
function viterbi(observations) {

    const dp = [];
    const backpointer = [];

    // Initialization

    dp[0] = {};

    for (const state of states) {

        dp[0][state] =
            initial[state] *
            emission[state][observations[0]];

        backpointer[0] = {};
    }

    // Recurrence

    for (let t = 1;
         t < observations.length;
         t++) {

        dp[t] = {};
        backpointer[t] = {};

        for (const current of states) {

            let bestProbability = -Infinity;
            let bestPrevious = null;

            for (const previous of states) {

                const probability =
                    dp[t - 1][previous] *
                    transition[previous][current] *
                    emission[current][observations[t]];

                if (probability > bestProbability) {

                    bestProbability = probability;
                    bestPrevious = previous;
                }
            }

            dp[t][current] = bestProbability;
            backpointer[t][current] = bestPrevious;
        }
    }

    // Backtracking

    let current = argMax(dp[observations.length - 1]);

    const path = [current];

    for (let t = observations.length - 1;
         t > 0;
         t--) {

        current = backpointer[t][current];
        path.push(current);
    }

    return path.reverse();
}
