Behind the state

Why would AI accept a worse move?

Simulated Annealing borrows an idea from physical annealing. Early in the search, the algorithm has enough "temperature" to escape local traps. As temperature decreases, the search settles down.

🔥

Start Hot

A high temperature means the algorithm is more willing to explore unfamiliar solutions.

🎲

Explore

Even a worse candidate can sometimes be accepted. This helps the search escape a local optimum.

🌤️

Cool Down

The temperature gradually decreases according to the cooling schedule.

🏆

Settle

At low temperatures, worse moves become unlikely, allowing the algorithm to stabilize around a strong solution.

The acceptance rule

A worse move isn't always rejected.

P(accept) = eΔE / T

When a candidate solution is worse, ΔE is negative. A higher temperature makes acceptance more likely, while a lower temperature makes the algorithm increasingly selective.

Implementation

See the core idea.

This simplified implementation demonstrates the central acceptance rule used by Simulated Annealing.

simulated-annealing.js 
function simulatedAnnealing(current, temperature) {

const candidate =
    getNeighbor(current);

const difference =
    candidate.score - current.score;

if (difference > 0) {
    return candidate;
}

const probability =
    Math.exp(difference / temperature);

if (Math.random() < probability) {
    return candidate;
}

return current;


}
