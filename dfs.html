Understand the algorithm

DFS loves going deeper.

Depth First Search explores one branch of a graph as far as possible before returning and trying another branch. This implementation uses an explicit stack so you can see the algorithm's state directly.

⬇️

Go deeper

DFS follows an available neighbour and continues deeper instead of immediately exploring every nearby node.

📚

Use a stack

The most recently discovered node is processed first. This gives DFS its last-in, first-out behaviour.

↩️

Backtrack

When a node has no unexplored neighbours, DFS returns to an earlier point and continues from there.

🎯

Find targets

DFS can be used to determine whether a target is reachable and to construct traversal paths through graphs.

Implementation

See the code behind DFS.

This is the core iterative idea used by the interactive visualisation above.

dfs.js 
function dfs(graph, start, target) {
const stack = [start];
const visited = new Set();

while (stack.length > 0) {

    const node = stack.pop();

    if (visited.has(node)) {
        continue;
    }

    visited.add(node);

    if (node === target) {
        return visited;
    }

    for (const neighbor of graph[node]) {
        if (!visited.has(neighbor)) {
            stack.push(neighbor);
        }
    }
}

return visited;


}
Time Complexity O(V + E)
Space Complexity O(V)
