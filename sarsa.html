Understand SARSA

Why is it called SARSA?

The name comes directly from the five elements involved in one learning transition.

S

State

The agent observes where it currently is in the environment. This is the state used to select an action.

A

Action

The agent chooses an action using its current policy, balancing exploration with exploitation.

R

Reward

The environment returns a reward after the action. This tells the agent whether the transition was useful.

S′

Next State + Action

SARSA then observes the next state and selects the next action. That actual next action is used in the update.

Implementation

The core SARSA update.

Unlike a purely decorative visualization, this page uses the same update rule shown below to modify the live Q-table.

function sarsaUpdate(
state,
action,
reward,
nextState,
nextAction


) { const currentQ =
Q[state][action];


const nextQ =
    Q[nextState][nextAction];

const target =
    reward + gamma * nextQ;

Q[state][action] =
    currentQ +
    alpha * (target - currentQ);

return Q[state][action];


}
