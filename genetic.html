Understand the algorithm

How does evolution become computation?

Genetic algorithms are optimization techniques inspired by natural selection. Instead of directly solving a problem, they repeatedly improve a population of candidate solutions.

📊

Fitness

Every candidate receives a fitness score based on how closely it matches the target. Better candidates receive higher scores.

🏆

Selection

Candidates with stronger fitness are more likely to become parents for the next generation.

🔀

Crossover

Two parent candidates are combined to produce a new candidate containing information from both.

✨

Mutation

Random character changes maintain diversity and allow the population to explore new possibilities.

Implementation

See the evolutionary loop.

The interactive experiment uses the same core ideas shown in this simplified implementation.

genetic-algorithm.js 
function evolve(population, target) {

    const scored =
        population.map(candidate => ({
            candidate,
            fitness: fitness(candidate, target)
        }));

    scored.sort((a, b) =>
        b.fitness - a.fitness
    );

    const parents =
        scored.slice(0, 4);

    const nextGeneration = [];

    while (
        nextGeneration.length <
        population.length
    ) {
        const parentA =
            chooseParent(parents);

        const parentB =
            chooseParent(parents);

        let child =
            crossover(parentA, parentB);

        child =
            mutate(child);

        nextGeneration.push(child);
    }

    return nextGeneration;
}
