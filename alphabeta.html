Understand the idea

Why can AI skip a branch?

Alpha-Beta Pruning works alongside Minimax. Once the algorithm already knows enough about a position, some remaining branches cannot possibly improve the result. Those branches can be ignored.

🔺

Alpha

Alpha represents the best value that the maximizing player can guarantee so far.

🔻

Beta

Beta represents the best value that the minimizing player can guarantee so far.

✂️

Cutoff

When alpha becomes greater than or equal to beta, the remaining siblings do not need to be explored.

⚡

Same answer, less work

Correct Alpha-Beta Pruning produces the same Minimax result while potentially examining fewer nodes.

Implementation

The pruning rule

This is the core idea behind Alpha-Beta search.

alphabeta.js 
function alphaBeta(
node,
depth,
alpha,
beta,
maximizingPlayer


) { if (depth === 0 || node.isTerminal) { return node.value;
}


if (maximizingPlayer) {
    let value = -Infinity;

    for (const child of node.children) {
        value = Math.max(
            value,
            alphaBeta(
                child,
                depth - 1,
                alpha,
                beta,
                false
            )
        );

        alpha = Math.max(alpha, value);

        if (alpha >= beta) {
            // Remaining branches are unnecessary.
            break;
        }
    }

    return value;
}

let value = Infinity;

for (const child of node.children) {
    value = Math.min(
        value,
        alphaBeta(
            child,
            depth - 1,
            alpha,
            beta,
            true
        )
    );

    beta = Math.min(beta, value);

    if (alpha >= beta) {
        // Remaining branches are unnecessary.
        break;
    }
}

return value;


}
Complexity

How much work can it save?

The exact number of visited nodes depends heavily on the ordering of moves and the structure of the tree.

Minimax worst-case O(bd)
Alpha-Beta best-case O(bd/2)
Extra search memory O(d)
