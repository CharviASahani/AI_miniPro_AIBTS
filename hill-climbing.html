Understand the algorithm

How does Hill Climbing work?

Hill Climbing is a local search strategy. Instead of exploring an entire search tree, it focuses on the current state and nearby alternatives.

📍

Choose a state

The algorithm begins with an initial solution or state. It evaluates how good that state currently is.

🔎

Inspect neighbours

Nearby states are examined to find possible improvements over the current position.

⬆️

Move uphill

If a neighbouring state has a higher value, the algorithm moves there and repeats the process.

🛑

Stop when stuck

If no neighbouring state is better, the algorithm stops. This can produce a local maximum instead of the global one.

Implementation

See the core decision loop.

The essential idea is simple: inspect neighbouring states, choose an improvement, and repeat until no improvement exists.

hill-climbing.js 
function hillClimb(currentState) {

while (true) {

    const neighbours =
        getNeighbours(currentState);

    const bestNeighbour =
        getBestNeighbour(neighbours);

    if (
        evaluate(bestNeighbour)
        <= evaluate(currentState)
    ) {
        return currentState;
    }

    currentState = bestNeighbour;
}


}
