Understand the algorithm

Four steps. One decision.

Unlike exhaustive search, MCTS spends computational effort where simulations suggest it matters most.

🔎

Selection

Starting from the root, MCTS repeatedly chooses a child using the UCT rule to balance exploitation and exploration.

🌱

Expansion

When an expandable state is reached, one of its unvisited actions becomes a new tree node.

🎲

Simulation

The new state is played out using a rollout policy. Here the simulation uses randomized legal moves.

↩

Backpropagation

The simulation result travels back through the selected path, updating visit counts and accumulated rewards.

Implementation

The engine behind MCTS.

The implementation below uses the standard UCT selection formula and performs genuine randomized rollouts.

function uctValue(node) {
if (node.visits === 0) {
    return Infinity;
}

const exploitation =
    node.wins / node.visits;

const exploration =
    Math.sqrt(
        2 *
        Math.log(node.parent.visits) /
        node.visits
    );

return exploitation + exploration;


}

function select(node) { while (
node.children.length > 0 &&
node.untriedMoves.length === 0
) {
node = node.children
.reduce((best, child) => uctValue(child) > uctValue(best)
? child
: best
);
}


return node;


}

function expand(node) { if (node.untriedMoves.length === 0) { return node;
}


const move =
    node.untriedMoves
        .splice(
            Math.floor(
                Math.random() *
                node.untriedMoves.length
            ),
            1
        )[0];

return node.addChild(move);


}

function backpropagate(node, result) { while (node !== null) {
node.visits++;
node.wins += result;
node = node.parent;
result = -result;
}
