Understand the idea

Bayesian thinking, simplified.

Bayesian reasoning is about changing a probability when new information arrives. The important part is not simply the evidence itself, but how expected that evidence is under competing explanations.

🌱

Prior

Your starting belief before the new observation. It represents what you thought was plausible initially.

🔎

Evidence

New information that can make one hypothesis more or less plausible compared with another.

✨

Posterior

The updated belief after combining the prior with the observed evidence.

Implementation

The calculation behind the screen.

This compact JavaScript function performs the core Bayesian update used by the interactive laboratory.

bayesian.js 
function bayesianUpdate(
prior,
evidenceGivenTrue,
evidenceGivenFalse


) { const evidence =
evidenceGivenTrue * prior +
evidenceGivenFalse * (1 - prior);


const posterior =
    (evidenceGivenTrue * prior) / evidence;

return posterior;


}
