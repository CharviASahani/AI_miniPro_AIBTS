Behind The State

Why did A* choose that node?

A* does not blindly explore every possible location. It combines the cost already travelled with a heuristic estimate of the remaining distance.

👣

g(n) — Cost so far

How far the algorithm has already travelled from the starting point to the current node.

🔮

h(n) — Heuristic

An estimate of how far the current node is from the goal. Here we use Manhattan distance.

⭐

f(n) — Total priority

The two values are combined to decide which node should be explored next.

🎯

Goal reached

Once the destination is reached, the algorithm follows the stored parent relationships backwards to reconstruct the final route.

f(n) = g(n) + h(n)   →   actual cost + estimated remaining cost
Understand the algorithm

How does A* think?

A* repeatedly chooses the most promising node from its frontier, explores its neighbours, and updates their estimated costs until it reaches the destination.

🧭

1. Start somewhere

A* begins at the selected start node and gives it an initial cost of zero.

🔍

2. Explore neighbours

The algorithm checks nearby walkable nodes and calculates the cost of reaching each one.

⚖️

3. Balance two costs

A* combines the travelled distance and heuristic estimate using f(n) = g(n) + h(n).

🏁

4. Reconstruct the path

After reaching the goal, A* follows parent links backwards to reveal the route from start to finish.

Implementation

See the idea behind A*.

This simplified implementation captures the central decision made by A*: choose the node with the lowest estimated total cost.

astar.js 
function aStar(start, goal) {

const openSet = [start];

start.g = 0;
start.h = heuristic(start, goal);
start.f = start.g + start.h;

while (openSet.length > 0) {

    const current =
        lowestFScore(openSet);

    if (current === goal) {
        return reconstructPath(current);
    }

    remove(openSet, current);

    for (const neighbour
        of getNeighbours(current)) {

        const tentativeG =
            current.g + 1;

        if (tentativeG < neighbour.g) {

            neighbour.parent = current;
            neighbour.g = tentativeG;
            neighbour.h =
                heuristic(neighbour, goal);

            neighbour.f =
                neighbour.g + neighbour.h;

            if (!openSet.includes(neighbour)) {
                openSet.push(neighbour);
            }
        }
    }
}

return null;


}
