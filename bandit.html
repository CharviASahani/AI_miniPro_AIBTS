Understand the algorithm

What is a Multi-Armed Bandit?

A multi-armed bandit models repeated decisions where an agent must choose between several actions whose reward distributions are initially uncertain.

🔎

Exploration

The learner deliberately tries actions whose value is uncertain so it can gather more information.

🎯

Exploitation

The learner chooses the action with the highest current estimated reward to make use of what it has learned.

📊

Value estimation

After every pull, the estimated value of the selected arm is updated using an incremental sample-average rule.

⚖️

The trade-off

Too much exploration wastes opportunities, while too little exploration can cause the learner to miss better actions.

Mathematical idea

How does the estimate change?

The implementation uses an incremental sample-average estimator, so the complete reward history does not need to be stored.

Qₙ₊₁ = Qₙ + 1/(Nₙ + 1) × (Rₙ₊₁ − Qₙ)
Q is the estimated value of an arm, N is the number of times that arm has been selected, and R is the newly observed reward. Each new observation moves the estimate toward the observed reward.

This is the core ε-greedy decision and incremental value-update logic used by the simulation above.

bandit.js 
function selectArm() {
    if (Math.random() < epsilon) {
        return randomArm();
    }

    return bestEstimatedArm();
}

function updateEstimate(arm, reward) {
    arm.count += 1;

    arm.value +=
        (reward - arm.value) / arm.count;
}

function step() {
    const arm = selectArm();
    const reward = sampleReward(arm);

    updateEstimate(arm, reward);
}
