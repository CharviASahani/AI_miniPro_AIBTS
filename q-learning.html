Understand the algorithm

What is Q-Learning?

Q-Learning is a model-free reinforcement learning algorithm. Instead of being given the correct answer, an agent learns which actions are useful by interacting with an environment and receiving rewards.

🎯

States

A state describes where the agent currently is. Here, every walkable grid position represents a possible state.

🎮

Actions

At each state, the agent can try actions such as moving up, down, left or right when those actions are available.

⭐

Rewards

Reaching the goal gives a positive reward while inefficient moves receive smaller feedback. The reward guides future decisions.

🔄

Experience

The agent repeatedly interacts with the environment. Over time, useful actions receive stronger Q-values and the learned policy becomes more effective.
