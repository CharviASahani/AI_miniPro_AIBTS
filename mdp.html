Understand the model

What makes an MDP an MDP?

A Markov Decision Process gives an agent a mathematical framework for making decisions when outcomes are uncertain. The agent repeatedly observes a state, chooses an action, receives a reward and transitions to another state.

◉

States

A state represents the information needed to describe the agent's current situation.

↗

Actions

Actions are choices available to the agent from a particular state.

◇

Transitions

The environment may respond probabilistically, meaning the same action can lead to different next states.

★

Rewards

Rewards quantify immediate outcomes while the discount factor determines how strongly future rewards matter.

Implementation

The decision rule behind the agent.

Value iteration repeatedly applies the Bellman optimality equation until the values describe the best achievable long-term returns.

value-iteration.js 
function valueIteration(states, actions, gamma) {

let values = {};

for (const state of states) {
    values[state] = 0;
}

for (const state of states) {

    let bestValue = -Infinity;

    for (const action of actions[state]) {

        let actionValue = 0;

        for (const transition of action.transitions) {

            actionValue += transition.probability *
                (
                    transition.reward +
                    gamma * values[transition.nextState]
                );
        }

        bestValue = Math.max(
            bestValue,
            actionValue
        );
    }

    newValues[state] = bestValue;
}

return newValues;


}
