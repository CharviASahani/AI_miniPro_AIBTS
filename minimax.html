Understand the algorithm

So, what is Minimax?

Minimax is a decision-making algorithm commonly used in turn-based, two-player games where one player tries to maximize the outcome while the opponent tries to minimize it.

🔮

Look ahead

The algorithm considers possible moves and the game states that could follow them.

⚖️

Max vs Min

The AI tries to maximize its result while assuming the opponent will make choices that minimize it.

🏁

Terminal states

Completed games receive scores. In this implementation: AI win = +1, draw = 0, AI loss = −1.

↩️

Backtracking

Scores are returned through the recursive game tree until the AI can compare its available moves.

Implementation

See the code behind the decision.

This simplified version shows the core recursive idea behind the Minimax implementation used by the game.

minimax.js 
function minimax(board, maximizingPlayer) {
const result = checkWinner(board);

if (result !== null) {
    return scoreTerminalState(result);
}

const moves = getAvailableMoves(board);

if (maximizingPlayer) {
    let bestScore = -Infinity;

    for (const move of moves) {
        board[move] = "O";

        const score =
            minimax(board, false);

        board[move] = "";
        bestScore = Math.max(bestScore, score);
    }

    return bestScore;
}

let bestScore = Infinity;

for (const move of moves) {
    board[move] = "X";

    const score =
        minimax(board, true);

    board[move] = "";
    bestScore = Math.min(bestScore, score);
}

return bestScore;


}
