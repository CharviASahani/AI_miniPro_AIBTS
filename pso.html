Understand the mechanism

Three forces guide the swarm.

PSO does not construct a search tree. Instead, it maintains a population of candidate solutions and repeatedly updates their positions using information shared throughout the swarm.

〰

Inertia

The inertia term preserves part of the particle's previous velocity, allowing particles to continue exploring the search space.

◎

Cognitive Pull

Each particle is attracted toward its own personal best position, representing what it has learned individually.

✦

Social Pull

Particles are also attracted toward the global best discovered by the swarm, allowing useful information to spread.

⌁

Continuous Search

Unlike graph algorithms such as BFS or Dijkstra, PSO operates naturally over continuous numerical search spaces.

Implementation

The PSO update rule.

This is the core numerical update used by every particle during each iteration of the simulation.

pso.js 
function updateParticle(particle, globalBest) {

    const r1 = Math.random();
    const r2 = Math.random();

    particle.vx =
        inertia * particle.vx
        + cognitive * r1
        * (particle.bestX - particle.x)
        + social * r2
        * (globalBest.x - particle.x);

    particle.vy =
        inertia * particle.vy
        + cognitive * r1
        * (particle.bestY - particle.y)
        + social * r2
        * (globalBest.y - particle.y);

    particle.x += particle.vx;
    particle.y += particle.vy;

    const value =
        objectiveFunction(
            particle.x,
            particle.y
        );

    if (value < particle.bestValue) {
        particle.bestX = particle.x;
        particle.bestY = particle.y;
        particle.bestValue = value;
    }
}
