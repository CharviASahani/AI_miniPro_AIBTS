What does Forward Checking do?

Forward Checking is a constraint-satisfaction technique. After assigning a value to one variable, it examines neighboring unassigned variables and removes values that can no longer be used.

🎯

Assign a variable

The solver chooses a variable and assigns one value from its current domain.

🔎

Look ahead

The solver immediately checks the domains of variables connected by constraints.

✂️

Remove conflicts

Values that conflict with the new assignment are removed from neighboring domains.

🚧

Detect dead ends

If an unassigned variable loses every possible value, the current path cannot produce a valid solution.

Forward Checking does not wait until the entire assignment is complete. It detects impossible future choices as soon as a constraint becomes relevant.
Implementation

See the core idea.

The essential operation is domain filtering after an assignment.

forward-checking.js 
function forwardCheck(variable, value) {

assignment[variable] = value;

for (const neighbor of neighbors[variable]) {

    if (assignment[neighbor] !== null) {
        continue;
    }

    domains[neighbor] =
        domains[neighbor].filter(
            candidate => candidate !== value
        );

    if (domains[neighbor].length === 0) {
        return false;
    }
}

return true;


}
